🌎 Bienvenidos a WaySpot

Este es el repositorio oficial de WaySpot, una aplicación móvil diseñada para descubrir, compartir y recomendar lugares turísticos y spots especiales.

WaySpot busca crear una comunidad en la que los usuarios puedan explorar lugares, compartir sus experiencias mediante reseñas y calificaciones, interactuar con otras opiniones y seguir a otros usuarios, facilitando el descubrimiento de nuevos lugares a través de experiencias reales.

En este repositorio se encuentra el código fuente, la documentación y los diferentes recursos utilizados durante el desarrollo del proyecto.

📍 Descubre. Comparte. Explora. — WaySpot
